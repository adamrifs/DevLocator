# DevLocator privacy policy

**Draft for publisher review.** Replace the contact placeholder and review the final extension and companion before publishing.

DevLocator helps users inspect webpage elements and locate their source code.

## Information DevLocator handles

When you use the inspector, DevLocator reads details of the selected element and its surroundings, including HTML, text, attributes, computed styles, selectors, dimensions, and available framework and source information. The extension also uses the current page's origin and path to associate a site with its source folder and search for matching files. Page content can contain information entered by users or displayed by a website.

DevLocator stores your preferences, including your chosen editor, theme, highlight settings, and project-folder mappings, in Chrome's local extension storage. It keeps details of your most recently inspected element in memory while the page is open. DevLocator may write a source location or selector to your clipboard when you request a copy or use the documented copy-on-failure action.

## Local companion and editor

If you install the Linux companion, DevLocator sends it the inspected element's matching details, the configured local project folder and page path to find a source location. It also sends a file path, line, column, and chosen editor when opening a source location. The companion searches supported local files in the configured project folder or, for a local HTML page, the opened file. It launches the chosen editor with the location. The companion and extension communicate locally through Chrome native messaging.

## Sharing and external services

The reviewed DevLocator extension and companion code do not send inspected data or project files to a developer-operated server, analytics service, or advertising service. The selected editor receives the file location when DevLocator launches it. The editor and Chrome operate under their own privacy practices. If you contact us, the service you use to contact us will process your message.

## Retention and removal

Chrome retains locally stored preferences and project-folder mappings until you change or clear them or remove the extension. Closing or refreshing the webpage clears its in-memory inspection details. Uninstalling the extension removes its Chrome local extension storage. Uninstalling the extension does not automatically remove a separately installed native companion or copies you placed on your clipboard.

## Changes

We may update this policy as DevLocator changes. The current policy will be available at the link in the Chrome Web Store listing.
